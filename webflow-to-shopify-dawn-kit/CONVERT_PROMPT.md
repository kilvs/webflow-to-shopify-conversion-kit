# Hands-off conversion brief (Dawn-augmented)

Paste this entire file as your **first message** to Claude Code (or any AI coding agent) once you've:

1. Unzipped your Webflow export into `webflow-source/`
2. Copied the `webflow-to-shopify-dawn-kit/` folder into the project root

The AI will run the conversion end-to-end. You review the final result and push to GitHub.

---

## YOUR TASK

You're converting a Webflow static-site export into a **hybrid** Shopify Online Store 2.0 theme:

| Pages | Source | Why |
|---|---|---|
| Homepage, about, contact, `/pages/*`, blog, articles, 404, password | **Webflow** | Brand design + interactions live in Webflow's CSS/JS bundle. Preserved verbatim. |
| Header, footer | **Webflow** | Shared across all pages so brand identity continues into the shop. |
| Product, collection, cart, search, customer account | **Dawn** | Battle-tested commerce templates. Don't rebuild what Shopify already ships. |

CSS conflicts between Dawn and Webflow are resolved by cascade layers (`@layer dawn, webflow;`) — Webflow wins on shared selectors.

**Working directory**: the project root (contains `webflow-source/` and `webflow-to-shopify-dawn-kit/`).

**Sources of truth:**
- `webflow-to-shopify-dawn-kit/DAWN_INTEGRATION.md` — Dawn-specific rules (cascade layers, cart drawer bridge, version pin, seam handling)
- `webflow-to-shopify-kit/CONVERSION_GUIDE.md` — the full Webflow → Shopify recipe (every Webflow gotcha; shared with the base kit)

Re-read them whenever stuck.

## STEP-BY-STEP

### 1. Run the orchestrator

```bash
bash webflow-to-shopify-dawn-kit/scripts/convert-all.sh   # or .ps1 on Windows
```

This handles install-skills, audit, flatten-assets (wraps Webflow CSS in `@layer webflow`), bootstrap starter-theme, pull-dawn, merge-dawn-commerce (wraps Dawn CSS in `@layer dawn`), extract Webflow brand pages, convert newsletter forms, audit CSS conflicts, and check for newer Dawn releases + required Shopify files. Expect 2–4 minutes (the Dawn clone takes the longest). If anything errors out, fix the underlying issue and re-run — every step is idempotent.

### 2. Fill `layout/theme.liquid` placeholders from `AUDIT.md`

Open `AUDIT.md` (generated by the audit step). Open `layout/theme.liquid` + `layout/password.liquid`. Replace every `<…>` placeholder:

- `<YOUR_WF_SITE_ID>` ← the **data-wf-site** value from AUDIT.md (one occurrence in theme.liquid, two in password.liquid because it appears in both the html attribute and jQuery src)
- `<WF_PAGE_INDEX>`, `<WF_PAGE_ABOUT>`, `<WF_PAGE_CONTACT>`, `<WF_PAGE_GENERIC_PAGE>`, `<WF_PAGE_BLOG>`, `<WF_PAGE_ARTICLE>`, `<WF_PAGE_404>`, `<WF_PAGE_401>` ← per-template **data-wf-page** values from AUDIT.md's table
- `<WEBFLOW_BUNDLE>.js` ← the JS bundle filename from AUDIT.md (e.g. `mysite-dev.js`). The string `<WEBFLOW_BUNDLE>` appears twice in each layout file.
- `<WEBFLOW_PRIMARY_CSS>` ← the brand's primary CSS filename from AUDIT.md (e.g. `mysite-dev.css`)

Note: there are **no** product/collection/cart/search placeholders — Dawn handles those templates and doesn't need `data-wf-page` attributes.

Then **also update the project's CLAUDE.md**: replace `<BRAND>` with the brand/project name and `<your-org>` with the GitHub org.

### 3. Build `sections/header.liquid` + `sections/footer.liquid` from `webflow-source/index.html`

These are unique per brand. The scripts can't auto-generate them.

**For header**:
1. Open `webflow-source/index.html`, find the `<header class="component_header">…</header>` block, copy it verbatim into `sections/header.liquid`.
2. Apply asset-URL rewrites: `src="images/X"` → `src="{{ 'X' | asset_url }}"`; internal `href="X.html"` → matching `{{ routes.* }}` URL (full mapping table in `webflow-to-shopify-kit/CONVERSION_GUIDE.md §4.3`).
3. Replace the inline logo with the conditional from the base kit's CONVERSION_GUIDE §C.
4. For the cart icon **important**: wire it to open Dawn's cart drawer. Add `data-cart-open` to the anchor (or use the snippet from `DAWN_INTEGRATION.md §Cart drawer bridge`). The badge becomes `<span class="cart-count-bubble">{{ cart.item_count }}</span>` — Dawn's `cart-icon-bubble.liquid` snippet renders this too if you'd rather use it.
5. Append a `{% schema %}` block with settings for `logo`, `main_menu`, `cta_label`/`cta_url`. Section group manifest: `sections/header-group.json`.

**For footer**: same approach with `<footer class="component_footer">`. Social row loops the 6 `settings.social_*_link` globals via `{% render 'social-icon', platform: platform %}`. Section group: `sections/footer-group.json`.

### 4. Wire Webflow "Add to cart" buttons to Dawn's cart drawer

If brand pages (homepage product slider, collection teaser, etc.) have "Add to cart" buttons that should drop items into the cart drawer Dawn provides:

```js
// snippet — add inside layout/theme.liquid before </body>, or in a new
// snippets/dawn-cart-bridge.liquid rendered by theme.liquid
document.querySelectorAll('[data-product-add], [data-cart-quick-add]').forEach(btn => {
  btn.addEventListener('click', async (e) => {
    e.preventDefault();
    const id = btn.dataset.cartQuickAdd || btn.closest('form')?.querySelector('[name="id"]')?.value;
    if (!id) return;
    const res = await fetch(Shopify.routes.cart_add_url, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ id, quantity: 1 })
    });
    if (res.ok) {
      // Trigger Dawn's cart drawer
      const drawer = document.querySelector('cart-drawer');
      drawer?.classList.add('animate', 'active');
      drawer?.dispatchEvent(new CustomEvent('cart:open'));
      // Refresh cart count badge
      document.querySelectorAll('[data-cart-count], .cart-count-bubble').forEach(el => {
        el.textContent = (parseInt(el.textContent || '0', 10) + 1).toString();
      });
    }
  });
});
```

Full example + variant details in `DAWN_INTEGRATION.md §Cart drawer bridge`.

## CONVENTIONS YOU MUST FOLLOW

These exist because they caused real bugs in past conversions.

- **Never modify** `assets/*.css` or `assets/*.js` (Webflow OR Dawn files). Style overrides go in theme settings → Custom CSS.
- **Never rename Webflow classes** — load-bearing for Webflow's CSS + bundled JS.
- **Never rename Dawn classes or custom-element tag names** (`<cart-drawer>`, `<product-form>`, `<variant-radios>`, etc.) — load-bearing for Dawn's web components.
- **Never strip `data-wf-*` attributes**.
- **The `@layer dawn`/`@layer webflow` wrapping is a narrow, documented exception** to "don't modify CSS." Each CSS file gets one `@layer NAME { ... }` wrapper applied by the scripts. Don't unwrap manually. Re-running `flatten-assets` and `merge-dawn-commerce` is idempotent.
- **Inside `{% liquid %}` tags**: one statement per line. Semicolons cause silent parse failure → Shopify reports cryptic "missing layout/theme.liquid" error.
- **Every image_picker setting needs a 3-tier fallback** (image_picker → fallback filename → hard-coded asset).
- **Every block-based section needs an `{% else %}` branch** inside its `{% for block in section.blocks %}` loop. Pair with `seed-template-blocks.cjs`.
- **Color settings should not have `default` values** unless verified against the actual CSS.
- **Check AUDIT.md** before configuring scripts — per-export filename / form-ID variation is real.
- **Section schema `tag` must be a valid value**, never `null`. Valid: `article`, `aside`, `div`, `footer`, `header`, `section`, or property omitted.
- **`{% sections %}` (plural) ≠ `{% section %}` (singular).** Plural = section group via `sections/<name>.json`. Singular = single section file.
- **Don't bring Dawn's `settings_schema.json` in wholesale** — it has ~200 lines of typography/color/spacing settings designed for Dawn's commerce sections. The kit's minimal schema is intentional. Bring Dawn settings in *one section at a time* if needed. See `DAWN_INTEGRATION.md §Settings schema`.
- **Don't overwrite `locales/en.default.json`** after the first run. `merge-dawn-commerce` only writes it if missing; on re-runs it's preserved so any merchant customizations survive.
- **Commit format**: Conventional Commits per project `CLAUDE.md`.
